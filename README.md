# SalaryFlow 💸

Sistema desenvolvido em Python para cálculo salarial, reajustes automáticos, descontos obrigatórios e projeções financeiras anuais.

---

## 📌 Funcionalidades

- Cálculo de salário bruto
- Aplicação de descontos:
  - INSS
  - IR
  - Sindicato
- Cálculo de salário líquido
- Aplicação de reajuste salarial automático
- Definição de faixa salarial
- Sugestão de investimento baseada na renda
- Projeção de salário acumulado anual
- Projeção de investimento acumulado

---

## 🧠 Regras do Sistema

### Reajuste Salarial

| Faixa Salarial | Reajuste |
|---|---|
| Até R$ 1800 | 20% |
| Até R$ 2700 | 15% |
| Até R$ 5500 | 10% |
| Acima de R$ 5500 | 5% |

---

### Sugestão de Investimento

| Faixa | Regra |
|---|---|
| A | Isento |
| B | Investir 10% |
| C | Investir 20% |
